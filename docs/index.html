Genau ein Job — gut gemacht

Keine Konfiguration, keine Account-Anmeldung, kein Ressourcen-Hunger.

🔍

Live-Übersicht

Auto-Refresh alle 3 Sekunden. Du siehst sofort, welche TCP-Ports lauschen — Port-Nummer, Prozess, PID, User.

🏷️

Dev-Port-Filter

Standardansicht zeigt nur die typischen Dev-Ports (3000, 4200, 5173, 8000, 8080…). Ein Toggle und du siehst alles.

🛑

Sicher beenden

SIGTERM für sauberen Shutdown. Falls der Prozess hängt, wird nach 2 Sekunden SIGKILL nachgeschoben.

🌐

Direkt im Browser

Klick aufs Safari-Symbol öffnet http://localhost:PORT. Datenbank-Ports werden automatisch ausgeblendet.

🪟

Popover oder Fenster

Schnell-Übersicht in der Menüleiste — bei Bedarf in ein vollwertiges Fenster mit Suche und Sortierung wechseln.

⚡

Native und schnell

Reines SwiftUI / AppKit. Kein Electron, keine Browser-Engine. ~360 KB Binary, 1.4 MB DMG.

In 30 Sekunden installiert

Zwei Wege — wähle was dir lieber ist.

ADMG installieren

  1. DMG-Download starten
  2. Image öffnen, App in Applications ziehen
  3. Erster Start: Rechtsklick → Öffnen → Öffnen
⬇ PortMonitor-1.2.0.dmg

BSelbst bauen

Voraussetzung: macOS 13+ und Xcode CLI Tools.

# Xcode CLI installieren falls nötig
xcode-select --install

# Repo klonen + bauen
git clone https://github.com/joelsommerer/PortMonitor.git
cd PortMonitor
./build-app.sh

# installieren + starten
cp -R PortMonitor.app /Applications/
open /Applications/PortMonitor.app
